# Tarot Reader Web App

An interactive tarot reading web application designed to make learning tarot cards more engaging, approachable, and customizable for beginners.

## Overview

Many online tarot readers automatically reveal cards and present large amounts of information at once, which can feel overwhelming for new users.

This project aims to recreate the experience of handling physical tarot cards digitally by allowing users to shuffle, spread, and select cards at their own pace while learning about tarot meanings through an accessible interface.

## Features

### Interactive Tarot Reading

* Shuffle cards
* Spread cards across the table
* Select cards manually
* Flip and reveal cards during readings

### Tarot Learning Library

* Browse tarot cards and their meanings
* Learn card interpretations at your own pace
* Explore different categories of card information

### Accessibility & Customization

* Theme support
* Adjustable font sizes
* High-contrast display options
* User-friendly interface for beginners

### Custom Card Support (Planned)

* Upload custom tarot card artwork
* Create personalized tarot decks

## Tech Stack

### Frontend

* React
* TypeScript
* Tailwind CSS

### Backend (Planned)

* Node.js

### Database (Planned)

* Firebase

## Project Goals

* Make tarot learning more interactive
* Reduce information overload for beginners
* Improve accessibility compared to traditional online tarot readers
* Provide opportunities for personalization and creativity
